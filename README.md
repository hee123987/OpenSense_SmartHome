# OpenSense SmartHome

**ESP32·MicroPython 기반 센서 모니터링 및 BLE 연동 스마트홈 자동 제어 시스템**

OpenSense SmartHome은 실내 환경과 재실·우천 상태를 감지하고, 조건에 따라 창문과 조명 등 장치를 제어하는 AIoT 스마트홈 팀 프로젝트입니다. ESP32 기반 하드웨어와 모바일 중심 웹 대시보드를 결합해 센서 상태를 확인하고 제어 기능을 사용할 수 있도록 구성했습니다.

- **개발 기간:** 2026년 7월 (교육 기간: 2026.07.21.~07.28.)
- **프로젝트 유형:** 팀 프로젝트
- **성과:** 2026년 AIoT 스마트홈 프로젝트 우수상
- **웹 대시보드:** https://opensense-smarthome-alpha.vercel.app/

> 웹 대시보드는 배포되어 있으나, 실제 센서값 수신 및 하드웨어 제어에는 ESP32 장치와 BLE 연결이 필요합니다. 사용 환경 및 브라우저의 Web Bluetooth 지원 여부에 따라 기능이 제한될 수 있습니다.

## 1. 프로젝트 개요

개별 센서의 측정값을 확인하는 데 그치지 않고, 여러 환경 조건을 종합해 스마트홈이 자동으로 동작하도록 구현하는 것을 목표로 했습니다. 특히 **재실 여부, 실내 온도, 빗물 감지 상태**를 함께 고려하고, 충돌하는 조건에서는 안전 관련 동작을 우선하도록 제어 흐름을 설계했습니다.

## 2. 주요 기능

| 기능 | 설명 |
| --- | --- |
| 실내 환경 모니터링 | 온습도, 조도, 인체 감지, 빗물 감지 상태 확인 |
| 자동 창문 제어 | 재실·온도 조건에 따른 환기 및 우천 시 창문 닫힘 우선 처리 |
| 수동 제어 | 웹 대시보드에서 창문, 조명, 음향 관련 제어 UI 제공 |
| 상태 시각화 | OLED, RGB LED, NeoPixel 등을 통한 시스템 상태 표시 |
| BLE 연동 | ESP32와 웹 대시보드 간 근거리 통신 기반 제어 |
| 모바일 웹 대시보드 | 주요 상태와 제어 기능을 화면별로 구성하고 Vercel에 배포 |

### 자동 제어 예시

1. 사람이 감지되고 실내 온도가 **29°C 이상**이면 환기를 위해 창문을 엽니다.
2. 빗물이 감지되면 환기 조건보다 우천 대응을 우선해 창문을 닫습니다.
3. 현재 상태에 맞춰 LED 및 OLED 표시를 갱신합니다.

## 3. 기술 스택

| 구분 | 기술 및 도구 |
| --- | --- |
| 임베디드 | ESP32 DEVKIT V1, MicroPython |
| 센서·출력 | DHT11, PIR, 빗물 감지 센서, CdS 조도 센서, 터치 센서, 서보모터, RGB LED, NeoPixel, OLED, 부저 |
| 통신 | Bluetooth Low Energy (BLE) |
| 웹 | HTML, CSS, JavaScript |
| 배포 | Vercel |
| 개발 지원 | 생성형 AI 기반 개발 도구(Google Antigravity) 활용 |

## 4. 시스템 구성

```text
[센서 입력]
온습도 · 인체 감지 · 빗물 · 조도 · 터치
          |
          v
   [ESP32 / MicroPython]
   상태 판단 및 제어 우선순위
          |
          +----> 서보모터 · RGB LED · NeoPixel · OLED · 부저
          |
          +----> BLE <----> 웹 대시보드 (HTML/CSS/JavaScript)
                                      |
                                      v
                                 Vercel 배포
```
