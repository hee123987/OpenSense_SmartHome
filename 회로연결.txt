# 🔌 ESP32 스마트홈 MicroPython 하드웨어 회로 연결 명세서

**피지컬 시스템 개요**:
본 피지컬 시스템은 ESP32 DEVKIT V1 보드를 중심으로 TTP223 터치 센서, RGB LED, CdS 조도 센서, SG90 서보 모터, DHT11 온습도 센서, 빗물 센서, PIR 인체 감지 센서, WS2812B 네오픽셀 LED, 피에조 부저, HD44780 I2C LCD, SSD1306 I2C OLED 디스플레이를 복합 제어하는 스마트홈 자동화 및 수동 제어 통합 시스템입니다.

**ESP32 기본 전원 스펙**:
- **보드 모델**: ESP32 DEVKIT V1 (30핀 사양)
- **작동 전원**: 3.3V / 5V (USB 전원 사용)
- **신호 전압**: 3.3V Logic Level

---

### 📌 컴포넌트별 핀 매핑 상세 명세

#### 1. TTP 정전식 터치 센서 (4채널 / 독립 모듈 4개)
- **모델**: TTP223 Capacitive Touch Sensor Module
- **입출력**: 디지털 입력
- **동작 특징**: 손가락 터치 감지 시 해당 GPIO 핀으로 HIGH(3.3V) 신호 발생, 미감지 시 LOW(0V)
- **핀 매핑**:
  - `D17` (GPIO17) ➔ 터치 센서 1 (Red LED 수동 ON)
  - `D5` (GPIO5) ➔ 터치 센서 2 (Green LED 수동 ON)
  - `D18` (GPIO18) ➔ 터치 센서 3 (Blue LED 수동 ON)
  - `D19` (GPIO19) ➔ 터치 센서 4 (조명 & 창문 전체 AUTO 모드 복귀)
  - `VCC` ➔ ESP32 3.3V
  - `GND` ➔ ESP32 GND

#### 2. RGB LED (1개)
- **모델**: 공통 캐소드(Common Cathode) 타입 3색 RGB LED
- **입출력**: 디지털 출력
- **핀 매핑**:
  - `D25` (GPIO25) ➔ RGB Red (빨강)
  - `D26` (GPIO26) ➔ RGB Green (초록)
  - `D27` (GPIO27) ➔ RGB Blue (파랑)
  - `GND` ➔ ESP32 GND

#### 3. CdS 조도 센서
- **모델**: 황화카드뮴(CdS) 광도전 셀 센서 모듈 (전압 분배 회로)
- **입출력**: 아날로그 입력 (ADC)
- **동작 특징**: 손으로 가리거나 주변이 어두워지면 읽기 값(ADC)이 상승함 (가릴 때 `DARK_THRESHOLD` 초과 시 자동 조명 켜짐)
- **핀 매핑**:
  - `D36` (GPIO36 / VP) ➔ 조도 신호선 (ADC1_CH0)
  - `VCC` ➔ ESP32 3.3V
  - `GND` ➔ ESP32 GND

#### 4. 서보 모터 (스마트 창문 제어용)
- **모델**: SG90 Micro Servo Motor
- **입출력**: PWM 제어 출력
- **동작 범위**: 90° (닫힘) ~ 135° (반개방) ~ 180° (완전 개방)
- **주의사항**: 동작 시 순간 전류가 크므로 작동 이상 발생 시 외부 5V 전원 연결 권장 (GND는 반드시 ESP32와 공통 연결)
- **핀 매핑**:
  - `D13` (GPIO13) ➔ 서보 제어 신호선 (PWM)
  - `VCC` ➔ ESP32 3.3V (또는 외부 5V 전원)
  - `GND` ➔ ESP32 GND

#### 5. 온습도 센서 (DHT11)
- **모델**: DHT11 Digital Temperature and Humidity Sensor Module
- **입출력**: 1-Wire 디지털 통신
- **핀 매핑**:
  - `D14` (GPIO14) ➔ DHT11 데이터 신호선 (OUT)
  - `VCC` ➔ ESP32 3.3V
  - `GND` ➔ ESP32 GND

#### 6. PIR 인체 감지 센서
- **모델**: HC-SR501 PIR Motion Sensor
- **입출력**: 디지털 입력
- **동작 특징**: 재실 여부 감지 (15초간 동작 감지 없으면 대기 상태로 전환되어 창문 닫힘)
- **핀 매핑**:
  - `D33` (GPIO33) ➔ PIR 신호선 (OUT)
  - `VCC` ➔ ESP32 3.3V (또는 5V)
  - `GND` ➔ ESP32 GND

#### 7. 빗물 감지 센서
- **모델**: Raindrops Sensor Module
- **입출력**: 디지털 입력
- **동작 특징**: 빗물 감지 시 LOW(0V) 출력 (비 감지 시 창문 즉시 강제 닫힘 + 경고 멜로디)
- **핀 매핑**:
  - `D34` (GPIO34) ➔ 빗물 센서 디지털 출력 (DO)
  - `VCC` ➔ ESP32 3.3V
  - `GND` ➔ ESP32 GND

#### 8. WS2812B 네오픽셀 LED (12구)
- **모델**: WS2812B 12-Bit Ring / Stick NeoPixel
- **입출력**: 디지털 제어 출력
- **동작 특징**: 스마트홈 현재 상태(정상/환기/우천/경고)에 따라 12개 LED 전체 색상 변경
- **핀 매핑**:
  - `D32` (GPIO32) ➔ 네오픽셀 Data In (DIN)
  - `VCC` ➔ ESP32 3.3V (또는 5V)
  - `GND` ➔ ESP32 GND

#### 9. 피에조 부저
- **모델**: 패시브 피에조 부저 (Passive Buzzer)
- **입출력**: PWM 주파수 출력
- **동작 특징**: 창문 열림/닫힘 멜로디 재생 (BLE 수신 명령 `20`/`21`로 음량 On/Off 가능
